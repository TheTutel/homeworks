# T-80БВМ
...модернизация основного боевого танка Т-80БВ семейства танков Т-80. Разработан и производится Омским заводом транспортного машиностроения (входит в Ростех). Контракт на модернизацию устаревших Т-80БВ до уровня Т-80БВМ был подписан с Минобороны РФ на форуме Армия-2017. Т-80БВМ находится на вооружении российской и украинской армии.
